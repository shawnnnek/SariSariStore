# My Sari-Sari POS

A small point-of-sale web page for a sari-sari store: tap or scan products, charge with change, track stock, and save backups. Works on an iPhone (add it to the Home Screen) and on a laptop.

Files: `index.html` (structure), `style.css` (look), `app.js` (logic), `sw.js` (offline copy), `manifest.webmanifest` + `icon-*.png` (Home Screen app).

Your products and sales are stored in the browser on each device. Use **Products > Save backup** regularly.
